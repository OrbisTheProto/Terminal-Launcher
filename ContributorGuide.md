# Contributor Guide
This is for people that want to contribute to this project for some reason, alongside personal rules
Last Updated with 0.3.1-Dev-20261024

## AI Policy
- Please avoid AI whenever possible, but it is permitted to be used with proper attribution.
- Proper AI code attribution in this project is shown as a comment before the code written saying that it has been written/edited by AI. An example of this is like the following:
"# Claude was used to write the following 3 lines
echo "Hi, Im AI Code!"
sleep 3
echo "I am properly attributed!""
Note that AI was not used to write this code, as it was just an example of proper attribution

## Guidelines
- Please follow the roadmap shown in README.md. I would like to keep it consistent
- If you would like to add to the roadmap, put a reason why in the PR (the reason will be removed if it is accepted)
- Non-roadmap items are OK to add in contributions as long as it can be added to a version patch increase reasonably
- Follow the AI Policy
- Feel free to add unnecessary spacing, as I have way too much BUT DON'T REMOVE IT!!
- Please avoid sudo/doas commands in the base project unless absolutely necessary.
    - If you want to have it in a mod, that's OK, but I want to keep the base script as much in the user profile as possible
- Feel free to suggest mods to be added into the base project (as long as they're licensed properly)
- Keep contributions in the same visual style unless you are overriding the visual style for everything in this project
- Keep contributions in Bash unless you add the necessary code to read your code
